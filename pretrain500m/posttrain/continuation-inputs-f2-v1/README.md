# F2 lineage-aware continuation inputs

This builder preserves the frozen F2 0.537B-token source quotas and both long-run
seed checkpoints. The long F2 exposure is added to each source's prior prediction
tokens; FineWeb-Edu also retains the earlier formal pretraining exposure. It
checks the new family-bound train pack, development/confirmation masked packs,
prefix-preserving benchmark exclusions, frozen selected-code license filter,
source-card snapshot and exact source epoch caps before writing a pilot-scoped
manifest, protocol and admission receipt.

The checkpoint parents are model-only finals, so the pilot initializes a new
optimizer and saves full state from its first run. Passing this input builder
does not launch GPUs, prove capability improvement or promote a model. Pilot
selection uses the new development pool; confirmation remains reserved until
after the paired runs, with independent capability and retention checks still
required before any broader claim.
