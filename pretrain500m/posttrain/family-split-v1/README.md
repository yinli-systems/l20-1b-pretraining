# Continuous family closure and partition assignment

This CPU stage consumes the completed, identity-bound quality features and raw
corpus exactly once. Sixteen MinHash bands propose pairs. Four workers compare
full unhashed Unicode-aware five-token shingle sets; a Jaccard score of at least
0.8 creates an edge. LSH collisions alone never certify a duplicate.

Canonical URLs, code repositories, exact text, normalized text, old-comparison
normalization and numeric templates form transitive document families. The old
NFKC/lowercase normalization groups conservatively but does not delete distinct
programs. Quality failures exclude individual records. Bound contamination or
old-source matches exclude their whole connected family. A bucket larger than
256 rows quarantines all its member families instead of silently truncating the
candidate search. A two-million-pair budget fails the stage if exceeded.

Deduplication chooses a passing representative after eligibility and family
quarantine. Development and confirmation each reserve at least 1,000 observed
families and 1,048,576 document prediction tokens per domain. This conservative
interpretation of the existing minimum is frozen before any candidate result.
The global family assignment precedes packing, including cross-domain families.
Deficits are explicit. No training pack or admission PASS is produced here.

The algorithm does not certify universal semantic independence, factual truth,
all repository forks, translations or exhaustive old-FineWeb near-duplicate
coverage. The sealed benchmark suite remains outside selection. Model quality
must still be measured. All original texts are preserved without modification.

Run `python -m unittest discover -s . -p 'test_*.py' -v` before deployment.
`scan.py --help` describes the required input hashes and paths. Output directories
are exclusive, input bindings are rechecked, and progress is atomically replaced.
