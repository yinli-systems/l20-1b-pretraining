# F2 continuation reserved validation pack

The combined F2 family audit has already selected eligible, observed-family-disjoint
development and confirmation documents. This wrapper checks the exact family and
selected-source pack hashes, every reserved stream and document index, source and
domain token totals, and family partition separation before reusing the frozen
document-masking core. It writes independent five-domain masked mixtures for the
two reserved partitions. Document-first tokens and padding carry no loss target.

The output is an evaluation artifact, not training admission or a sealed final
capability result. Development is for pilot decisions; confirmation is held back
from those decisions.
