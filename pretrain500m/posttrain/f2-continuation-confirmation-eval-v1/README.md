# Frozen paired F2 continuation confirmation

`plan.json` was created before opening or evaluating the reserved confirmation data. It binds the two completed F2 continuation full-state checkpoints and each matched historical model-only parent to exact SHA-256 identities, plus the previously audited family-disjoint five-domain masked confirmation manifest. `evaluate.py` verifies the plan, confirmation manifest and content, and every checkpoint before distributed four-5090 evaluation. The same reserved targets are evaluated for all four checkpoints, with an exact 11,045,058 valid-target count check.

The frozen gate requires both seeds to lower equal-domain masked loss against their own parent and no domain to regress by more than 0.5% for either seed. Failed quality gates still write a complete result JSON before exiting with a nonzero status. The result measures language-model loss only; separate capability, retention, benchmark contamination, and comparable external-model evaluation are required before promotion or market claims.

Deployment and Slurm submission depend on live controller and GPU checks. Neither the existence of this frozen plan nor a successful scheduler submission is a confirmation result.
