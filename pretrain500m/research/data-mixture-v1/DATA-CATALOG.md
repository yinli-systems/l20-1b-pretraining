复现索引与采样：

```sh
python3 pretrain500m/research/data-mixture-v1/collect_sources.py
python3 pretrain500m/research/data-mixture-v1/acquire_samples.py
python3 pretrain500m/research/data-mixture-v1/acquire_samples.py --supplemental
python3 pretrain500m/research/data-mixture-v1/rehydrate_code_samples.py
python3 pretrain500m/research/data-mixture-v1/plan_tokens.py
```

收集器重新运行会刷新 main 的元数据；复现本轮样本应保留现有 source-inventory.json，不重新解析 main。完整 SHA 及本地文件 hash 均在 JSON 记录中。
